# homebrew-boopstash

Homebrew tap for [Boopstash](https://github.com/lemehmet/boopstash), a scratch
pad for macOS that keeps what you paste: searchable, private, on-device.

```sh
brew install --cask lemehmet/boopstash/boopstash
```

The cask installs the signed and notarized app from Boopstash's
[releases](https://github.com/lemehmet/boopstash/releases). It is updated
automatically by Boopstash's release workflow; issues and contributions belong
in the [main repository](https://github.com/lemehmet/boopstash), where the cask
template lives at `packaging/homebrew/boopstash.rb`.
